# 이슈 30 분석 및 구현 결정 요청

- 이슈: [#30 파구스 개발 개요](https://github.com/pushwing/varius/issues/30)
- 분석일: 2026-08-26
- 상태: 기본 결정 완료, 구현 착수 가능

## 1. 이슈 요약

파주 맛집을 지도와 검색으로 공개하고, 회원가입 없이 단일 운영자가 맛집과 카테고리를 관리하는 MVP 요구사항이다.

주요 요구사항은 다음과 같다.

- 비회원 공개 지도와 맛집 목록
- 상호명·카테고리·동네 검색 및 필터
- 운영자 로그인과 운영자 메뉴
- 카테고리 관리
- 맛집 등록·수정·숨기기·검색
- 카테고리, 상호, 연락처, 홈페이지, 사진, 설명, 메뉴, 태그 관리
- 지도 클릭 또는 주소 검색을 통한 위치 입력
- 홈·문의하기·로그인 네비게이션
- 식신 등 외부 사이트의 참고 데이터 조회

## 2. 현재 상태

현재 Pagus 디렉터리에는 구현 코드가 없고 `AGENTS.md`, `README.md` 및 Graft 메타데이터만 있다. 따라서 기존 기능의 재사용이나 버그 수정이 아니라, 인증·스키마·공개 화면·운영 화면을 새로 설계하고 구현해야 한다.

## 3. 핵심 불변식

- 공개 화면에는 `restaurants.is_published = 1`인 맛집만 노출한다.
- 위도는 `-90..90`, 경도는 `-180..180` 범위로 서버 검증한다.
- 운영자 권한은 화면이 아닌 서버에서 검사한다.
- 숨기기는 삭제보다 상태 전이로 처리해 복구 가능성을 보존한다.
- 맛집과 카테고리의 다중 테이블 변경은 Service 트랜잭션으로 처리한다.
- 상태 변경 요청에는 CSRF 보호를 적용한다.
- 사진 업로드는 MIME·확장자·크기를 검증하고 웹 루트 밖에 저장한다.
- 공개 목록에는 공개 상태 조건, 정렬, 페이지네이션을 명시한다.

## 4. 구현 판단

### 운영자 인증

회원가입이 없으므로 초기 운영자 계정 생성 방식이 필요하다. 초기 MVP에서는 seed 또는 CLI로 운영자 계정을 한 번 생성하고, 일반 회원가입은 제공하지 않는 방식을 권장한다.

### 지도와 주소 검색

같은 저장소의 Iter가 사용하는 지도 레이어를 재사용한다. 기준 구현은 `Iter/app/Views/map.php`이며, `Leaflet.js + OpenStreetMap` 기반이다. Pagus에서도 동일한 지도 표시 구조를 우선 활용한다. 주소 검색 제공자와 API 키는 Iter의 실제 설정을 확인해 연결한다. 지도는 표시와 위치 선택에만 사용하고 공개 여부·권한 같은 비즈니스 규칙은 서버가 결정한다.

### 사진 저장

업로드 파일은 `public/` 외부 저장을 기본으로 한다. MVP에서는 로컬 저장으로 시작할 수 있지만, 운영 배포를 고려하면 S3 호환 스토리지로 확장 가능한 경계를 두는 것이 좋다.

### 외부 참고 데이터

식신 등 외부 사이트의 참고 데이터 조회는 MVP에 포함한다. 다만 공식 API 제공 여부와 이용약관을 먼저 확인하고, 허용된 방식으로만 연동한다. 외부 호출 실패나 제공 필드 부족 시 운영자가 직접 입력할 수 있어야 하며, 외부 데이터가 공개 상태나 권한 판단을 대신하지 않도록 한다.

## 5. 권장 구현 순서

1. 인증·운영자 권한과 기본 스키마
2. 카테고리 및 맛집 관리 CRUD
3. 공개 지도·목록·검색
4. 주소 검색과 지도 위치 입력
5. 사진·메뉴·태그 상세 관리
6. 문의하기
7. 허용된 외부 데이터 연동

## 6. 확정된 결정사항

- 운영자 인증: 운영자 계정 1개만 사용하고, 일반 회원가입은 제공하지 않는다.
- 지도: 같은 저장소의 Iter 지도 구현(`Leaflet.js + OpenStreetMap`)을 재사용한다.
- 사진: 서버 로컬 저장을 사용한다. `public/` 외부 저장과 업로드 검증은 유지한다.
- 메뉴·영업 정보: MVP에 포함하며 1차는 자유 텍스트 중심으로 구현한다.
- 외부 참고 데이터: MVP에 포함한다. 공식 API·약관을 확인하고 허용된 방식으로 연동한다.
- 문의하기: DB에 저장하고 운영자 화면에서 확인한다.

## 7. 추가 확인이 필요한 운영 정책

구현 중 임의로 정하지 않고 다음 항목은 세부 설계 시 확인한다.

- 운영자 계정의 비밀번호 재설정 방식
- Iter의 지도 구현에서 실제로 사용하는 주소 검색 제공자와 자격증명 설정
- 외부 참고 데이터 제공자의 공식 API·호출 제한·저작권 및 표시 조건
- 문의 목록의 처리 상태와 보관 기간
